# 脆皮泡芙壳 DIY 带货短视频

## 交付物

| 文件 | 说明 |
|------|------|
| `output/脆皮泡芙壳_DIY带货短视频.mp4` | 成片（约 30s / 1080×1920 / 含中文口播+字幕） |
| `文案口播.md` | 完整口播、钩子备选、买点、标题标签 |
| `frames/` | 8 张竖屏关键帧 |
| `build_video.py` | 可重复生成脚本（改文案后重跑即可） |

## 成片结构

1. 钩子：谁说做泡芙一定要烤箱？
2. 产品：开箱即用金黄脆皮壳
3. 质感：咖嚓脆顶特写
4. 证明：掰开全空心
5. DIY：挤奶油 → 水果装饰 → 成品盘
6. CTA：现货直发 · 你只负责好看

## 重新生成

```bash
cd 日常处理/脆皮泡芙壳营销视频
python3 build_video.py
```

依赖：`ffmpeg`、`edge-tts`（`pip install edge-tts`）
