## 钩子设计（前 3 秒必须停住下滑）

| 钩子类型 | 画面 | 文案 |
|---|---|---|
| 价格反差 | 女生把泡芙举到镜头前 | 甜品店一个38？我自己做才几块钱 |
| 听觉钩子 | 掰壳特写 + 脆响 | 你听这声音——咔 |
| 视觉钩子 | 掰开巨大空心 | 一掰全空，能塞超多奶油 |
| 结果钩子 | 图三成品闪切 | 5分钟出一盘ins风 |

成片把四个钩子叠进前 8 秒：价格 → 脆响 → 空心 → 产品托盘。

---

## 卖点（全部围绕「壳」）

1. **最难的已经做完**：泡芙失败 90% 出在烤壳，塌、软、不空、不脆。
2. **脆皮 craquelin**：表面砂金裂纹，入口先脆后香。
3. **心够空**：薄壁大肚，奶油水果能装很多，看起来就高级。
4. **开箱即用**：不用打发面糊、不用烤箱、不用失败重烤。
5. **5 分钟出片**：挤馅 + 摆水果 = 甜品店同款，适合送礼和拍视频。
6. **一个壳多种吃法**：鲜奶油水果、冰淇淋、巧克力、咸蛋黄都可以。
